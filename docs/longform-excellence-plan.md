## 2. 明确不做

- P3 章节任务队列、刷新后续跑、分章 TTS 自动合成
- 向量查重、新数据库
- 真实付费模型联调（用本地 mock）
- 画面圣经 / 生图 / 导出契约改动

## 3. 完成标准（可验收）

1. 30s 直接写稿；90s 先出轻提纲，不点确认也能「按提纲写稿」；181s 未确认不能写正文。
2. 钩子章窗口允许短钩子，不再因 38 字否决 90s。
3. 编辑提纲后已写章节标 `needs-revision`，锁定章不变。
4. 第 3 章失败时，第 1–2 章仍在工作区。
5. 实测 194s / 目标 180s 时，计划不含 hook、cta、locked。
6. `npm run lint`、`npm test`、`npm run build` 通过。
